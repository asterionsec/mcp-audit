# Changelog

## 0.1.0

First release.

- Reads Claude Code, Claude Desktop, Cursor, Codex, Gemini CLI, VS Code, Windsurf and Cline configurations.
- Rules for version pinning, plain-text credentials, unencrypted remote servers, broad filesystem access, privileged containers, shell bootstraps, auto-approval, file permissions and unparseable files.
- `--probe` checks tool descriptions of local stdio servers for hidden characters, model-directed instructions and shadowed tool names.
- Text, JSON and SARIF 2.1.0 output; MCP server mode with a read-only tool.
